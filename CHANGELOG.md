# Changelog

All notable changes to KnowledgeOS are documented in this file.

## [1.0.0] — 2026-07-17

### Added

- Phase 1 MVP Chrome extension (Manifest V3)
- Webpage text highlighting with floating toolbar and context menus
- Persistent highlights restored after page refresh (IndexedDB + Dexie)
- Markdown notes with character counter
- Tags and collections management
- Chrome side panel with search, filters, and virtualized lists
- PDF.js viewer with selection highlighting and notes
- Export to Markdown, JSON, and plain text
- Popup with today’s highlights, recent items, and quick search
- Options page for theme, font size, default color, backup, and shortcuts
- Keyboard shortcuts for highlight, note, and sidebar
- Light/dark/system themes
- Documentation: README, installation, architecture, contributing, roadmap

### Notes

- Offline-first only — AI and cloud sync intentionally deferred to later phases
