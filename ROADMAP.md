# Roadmap

## Phase 1 — MVP (current)

- [x] Webpage highlighting + floating toolbar
- [x] Persistent IndexedDB storage (Dexie)
- [x] Notes, tags, collections
- [x] Side panel with search/filters/export
- [x] Popup + options
- [x] PDF.js viewer highlighting
- [x] Markdown / JSON / text export
- [x] Dark/light themes and shortcuts

## Phase 2 — Organization polish

- [ ] Full-text index for very large libraries
- [ ] Highlight nesting / quote threads
- [ ] Import from Markdown/JSON backups
- [ ] Richer PDF annotation tools (freehand, area)
- [ ] Optional encrypted local vault passphrase

## Phase 3 — Optional sync (still privacy-first)

- [ ] User-controlled sync adapter (`FutureSyncAdapter`)
- [ ] Conflict-free merge for highlights
- [ ] End-to-end encrypted sync backends
- [ ] Multi-device settings sync

## Phase 4 — Optional AI (local-first)

- [ ] On-device summarization adapter (`FutureAiAdapter`)
- [ ] Tag suggestions from local models
- [ ] Semantic search with local embeddings
- [ ] Explicit opt-in only — never required for core capture

## Non-goals for early phases

- Mandatory accounts
- Silent telemetry
- Vendor lock-in to a single cloud AI provider
